Pind Manak YouTube Automation

Pind Manak YouTube Automation is a private automation system used to manage the Pind Manak YouTube channel and its continuous live broadcasts.

The system uses the YouTube API to manage live broadcasts, broadcast schedules, stream configuration, titles, descriptions and thumbnails.

The application is intended only for authorised administrators of the Pind Manak YouTube channel and is not offered as a public service.
